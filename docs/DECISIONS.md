# Решения

Правило: при конфликте материалов старого проекта Wastland с README Block-96 приоритет у Block-96 (решение владельца, 2026-11-20).

| Тема | Решение |
|---|---|
| Время/мир | 1996 катастрофа, 2003 — настоящее; лор Люмена/«Каскад»/ОСЬ не используется |
| Валюта | жетоны метро («энергетические токены»), «светляки» заменены |
| Территории | сеточные метки (X, Y, Layer), жетоны, окна уязвимости; личная база-участок 30×50 не переносится как есть |
| Камера | изометрия (выбор владельца 2026-11-20; README говорит «top-down» — приоритет за решением владельца) |
| Режим | экстракшен PvPvE, общий мир, временные отряды; разработка сразу как мультиплеер (без одиночной стадии) |
| Прицел | прямая линия и крестик, без цвета дальности (README молчит, прежнее решение сохраняется) |
| Движок | Godot 4 (выбор владельца, 2026-11-20); язык и бэкенд — открыты, см. TECH_DECISION.md |
| Размер первой версии | Один район (выбор владельца 2026-11-20, подтверждено правкой сообщения); какой район — открыто. Слои пока только Z=0 |
