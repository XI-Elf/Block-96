# BLOCK-96 — инструкции для Codex

## Контекст
Исходная контрольная сборка: v73. Цель — развитие существующего мобильного браузерного 2D extraction-проекта, не создание новой игры. Перед работой прочитай `docs/handoff/BLOCK96_CONTEXT.md`, `docs/handoff/ROADMAP.md`, `docs/handoff/TASK_V74.md`. Для технических выводов сверяй `docs/handoff/AUDIT_V73.md` с актуальным кодом. Визуальные требования: `docs/handoff/VISUAL_STYLE.md`.

## Инварианты
- Склад убежища **сохраняется после смерти**. Это подтверждённое владельцем правило. Не изменять его; рейдовые потери — отдельная механика.
- Сохранять текущую камеру, управление, игровую концепцию и географию города. Атмосферу видеореференсов адаптировать к текущей перспективе.
- Не сокращать население, территорию, функциональность или качество игровой видимости ради оптимизации без согласования.
- Не менять баланс, фракции, экономику, движок, формат сохранения с потерей совместимости или существующие ассеты без явного задания.
- Не считать старые PDF актуальной спецификацией v73. При противоречии фиксировать его и проверять код; явно согласованное правило владельца имеет приоритет.

## Процесс
1. Проверить рабочее дерево и состояние Git; сохранить исходную контрольную версию, не перезаписывать изменения владельца.
2. Определить границы одного задания, воспроизвести проблему, записать исходный результат и условия запуска.
3. Внести минимальное проверяемое изменение; не расширять объём задачи и не ослаблять тесты для зелёного результата.
4. Запустить целевые тесты, затем доступные регрессии. Отдельно фиксировать FAIL, PASS, SKIP, TIMEOUT и то, что не запускалось.
5. Для производительности сравнивать одинаковые seed, сценарий и устройство; фиксировать P50/P95/P99, boot, память. Node benchmark не равен мобильному FPS.
6. Документировать изменённые файлы, результаты, риски, ограничения, обратимость и ручные проверки. Не заявлять об успехе без измерений.
7. Остановиться на контрольной точке. Следующий этап — после подтверждения владельцем; не публиковать релиз и не выполнять push без разрешения.

## Текущий приоритет
v74: воспроизводимость тестов, проверка PPS-селектора, защита сохранений, базовые измерения и проверка карты. Начать с подзадачи v74.1 в `docs/handoff/TASK_V74.md`. Дальнейшие этапы — план, а не разрешение выполнить все одновременно.
